Frequently asked questions

How SwarmWeaver keeps concurrent coding agents predictable on real repositories.

Why split waves at compile time if runtime file locks exist?

Runtime locks stop silent overwrites, yet two agents launched blindly in parallel still waste a worker slot waiting or colliding. Compiling conflict-free waves beforehand schedules independent files together and sequences conflicting writes deterministically.

Can two agents edit different functions in the same file concurrently?

Yes. When both tasks narrow their scope using symbol qualifiers such as src/auth/jwt.py::verify_token and src/auth/jwt.py::rotate_keys, normalized scope intersection treats them as disjoint symbol locks.

What happens if someone edits or corrupts a checkpoint journal on disk?

swarmweaver verify-journal and CheckpointJournal.verify_integrity() recompute every canonical SHA-256 link against prev_hash and flag the exact tampered_sequence record.
